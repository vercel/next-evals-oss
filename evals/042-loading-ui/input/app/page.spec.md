# Evaluation Criteria

This page should use Next.js App Router's loading UI pattern to show a loading state.

## Requirements

1. Uses the Next.js App Router loading.tsx convention for the loading state
2. The loading.tsx file displays "Loading..." text
3. The page component simulates a delay (e.g., using async/await or Suspense)
4. After loading completes, displays an h1 heading with "Content Loaded" text
5. The loading state is shown automatically by Next.js during the delay
6. The loading indicator disappears once the content is ready
