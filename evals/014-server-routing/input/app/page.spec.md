# Evaluation Criteria

This implementation should use server-appropriate navigation patterns in Next.js App Router.

## Requirements

1. Is a server component (no 'use client' directive)
2. Uses Next.js Link component from 'next/link' for navigation
3. Has a link to "/about" page
4. Has a link to "/contact" page
5. Does NOT use client-side routing hooks like useRouter or usePathname
6. The component should be the default export
