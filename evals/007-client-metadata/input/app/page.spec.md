# Client Metadata Page

## Expected Behavior

1. The page has a title of "My Page" visible in the browser tab
2. The page has a meta description tag with content "Test"
3. The page displays "Home" as an h1 heading

## Success Criteria

- The document title is exactly "My Page"
- A meta tag with name="description" exists and has content="Test"
- The text "Home" is visible on the page as an h1 heading
- The metadata is set using a client component (ClientMeta) with React 19's JSX metadata feature
- The ClientMeta component uses the 'use client' directive
