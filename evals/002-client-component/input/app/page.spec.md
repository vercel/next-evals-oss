# Evaluation Criteria

This component should be a client-side React counter.

## Requirements

1. Uses 'use client' directive - required for client-side interactivity in Next.js App Router
2. Uses React useState hook to manage the count state, initialized to 0
3. Displays the current count in the format "Count: X" where X is the number
4. Has a button labeled "Increment" that increases the count by 1 when clicked
5. The component should be the default export
