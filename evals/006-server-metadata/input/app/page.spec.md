# Server Metadata Page

## Expected Behavior

1. The page has a title of "My Page" visible in the browser tab
2. The page has a meta description tag with content "Test"
3. The page displays "Page Content" as visible text

## Success Criteria

- The document title is exactly "My Page"
- A meta tag with name="description" exists and has content="Test"
- The text "Page Content" is visible on the page
- The metadata is configured using Next.js static Metadata API (exported metadata object)
