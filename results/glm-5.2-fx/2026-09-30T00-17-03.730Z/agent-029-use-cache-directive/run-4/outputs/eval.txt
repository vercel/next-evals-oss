/**
 * Inline Server Action: the \"Sync latest catalog\" trigger.
 *
 * `revalidateTag` marks the `\"products\"` cache tag as stale instead of purging
 * and recomputing synchronously. The action returns immediately, so the admin
 * keeps working off the (briefly stale) cached snapshot. The catalog is then
 * refreshed in the background (stale-while-revalidate) and every view sharing
 * the `\"products\"` tag converges to the fresh data shortly after — without
 * forcing each request to block on freshly recomputed data.

 *
 * The underlying query (`getAllProducts`) only runs on a cache miss. Day-to-

 *
